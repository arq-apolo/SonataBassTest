# SonataBassTest
Native Android test app for relative car-audio bass roll-off.

## Build
GitHub Actions automatically builds a debug APK on every push to `main`.
Open **Actions → Build SonataBassTest APK → latest run → Artifacts → SonataBassTest-APK**.

## Measurement note
This is an experimental relative acoustic test, not a calibrated SPL meter. Keep the phone fixed and cabin conditions unchanged.
